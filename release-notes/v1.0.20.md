# V1.0.20

## 로그인 시 자동 실행과 백그라운드 동작

- 이 버전을 설치한 뒤 앱을 한 번 실행하면 Windows·macOS 로그인 시 자동 실행이 등록됩니다.
- 로그인 시 창 없이 백그라운드에서 실행되며, 창을 닫아도 트레이에 유지됩니다.
- Windows 알림 영역 또는 macOS 메뉴 막대의 앱 아이콘에서 창 열기, 자동 실행 설정 변경, 앱 종료를 할 수 있습니다.
- 이미 백그라운드에서 실행 중인 앱을 다시 실행하면 기존 창을 표시합니다.
- 최초 등록 이후에는 운영체제에서 자동 실행을 끈 설정을 덮어쓰지 않습니다.

## 설치 파일

- Windows: 설치 프로그램 및 포터블 ZIP
- macOS: Intel 및 Apple Silicon DMG, 자동 업데이트용 ZIP

표시 버전과 자동 업데이트용 내부 버전은 모두 1.0.20입니다.

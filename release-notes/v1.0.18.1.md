# V1.0.18.1

- 기본 API 주소를 `https://api.pc-management-assistant.setupmaru.com/api`로 변경했습니다.
- 기존 외부 도메인 두 개를 접속 후보에서 제거했습니다. 이전 사용자 설정에 남아 있는 구 도메인도 사용하지 않습니다.
- 설치된 앱은 새 HTTPS 도메인에 먼저 접속합니다. DNS 설정 중에도 서버와 같은 내부망에서는 서버 IP로, 서버와 같은 PC에서는 localhost로 접속할 수 있습니다.
- 접속에 성공한 주소는 앱을 종료할 때까지 우선 사용해, 같은 DNS 실패로 요청이 반복 지연되는 일을 방지합니다. DNS와 HTTPS 설정 후 앱을 다시 실행하면 새 도메인에 먼저 접속합니다.

## 서버 연결 안내

새 도메인은 DNS 등록과 HTTPS 프록시·인증서 설정이 완료되어야 외부에서 접속할 수 있습니다. 앱 업데이트만으로 DNS 레코드가 생성되지는 않습니다. 설정 방법은 저장소의 `server/OPERATIONS.md`를 참고해 주세요.

공개 버전은 `1.0.18.1`이며 자동 업데이트 비교에 사용하는 내부 SemVer는 `1.0.19-revision.1`입니다.

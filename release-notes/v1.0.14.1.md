## v1.0.14 대비 변경사항

### OpenAI 채팅 보안 강화

- 데스크톱 앱이 OpenAI API를 직접 호출하지 않고, 인증된 PC Management Assistant 서버를 통해 응답을 받도록 변경했습니다.
- OpenAI API 키를 데스크톱 앱 설정·로컬 저장소·빌드 결과물에서 제거하고 서버 환경 변수로만 관리합니다.
- 이전 버전에서 로컬에 저장한 OpenAI API 키는 앱 시작 시 자동으로 삭제합니다.
- 서버 채팅 API에 메시지 길이, 대화 수, 이미지 개수와 데이터 크기 검증을 추가했습니다.
- 이미지 원본은 현재 요청에만 사용하고 이후 대화 기록에는 첨부 사실만 남겨 불필요한 전송량을 줄였습니다.

### 플랜별 채팅 제어

- Free 플랜은 AI 채팅을 사용할 수 없고, Plus 플랜은 하루 5회, Pro 플랜은 무제한으로 서버에서 검증합니다.
- Plus 사용량 증가를 원자적 DB 연산으로 처리해 동시 요청으로 일일 한도가 초과되는 문제를 막았습니다.
- 채팅 화면의 사용량 표시와 한도 안내를 Plus 정책에 맞게 정리했습니다.

### 설정 및 운영

- 데스크톱 설정에서 OpenAI API 키 입력·저장·삭제 UI를 제거하고 구독 관리 화면에 집중하도록 단순화했습니다.
- 서버용 `OPENAI_API_KEY`, `OPENAI_MODEL` 설정과 운영 배포 안내를 추가했습니다.
- OpenAI 서버 오류, 빈 응답 및 미설정 상태를 사용자에게 안전한 메시지로 전달하도록 개선했습니다.

## 설치 파일

- `PC-Management-Assistant-1.0.14.1-setup.exe`: Windows 설치 프로그램
- `PC-Management-Assistant-1.0.14.1-windows-portable.zip`: Windows 포터블 버전
- `PC-Management-Assistant-1.0.14.1-mac-x64.dmg`: Intel Mac 설치 이미지
- `PC-Management-Assistant-1.0.14.1-mac-arm64.dmg`: Apple Silicon Mac 설치 이미지
- macOS ZIP 파일은 자동 업데이트용 패키지입니다.

> macOS 패키지는 Apple Developer ID 서명 및 공증이 적용되지 않았습니다. 처음 실행할 때 Finder에서 앱을 Control-클릭한 후 **열기**를 선택해야 할 수 있습니다.

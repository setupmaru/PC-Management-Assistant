## v1.0.15 대비 변경사항

### 백오피스 PC 관리 연동

- 로그인한 PC의 장비 상태를 PC Management Assistant API와 데이터베이스에 주기적으로 동기화합니다.
- 장비 이름, 운영체제, 앱 버전, CPU·GPU·메모리·디스크 상태와 마지막 접속 시간을 백오피스 PC 관리 탭에서 확인할 수 있습니다.
- PC Assistant 계정 이메일과 백오피스 고객 이메일이 같으면 해당 고객의 PC로 자동 연결됩니다.
- 마지막 보고 시간을 기준으로 온라인·오프라인 상태를 구분합니다.

### 보안 및 안정성

- 장비 상태 전송은 로그인 토큰으로 인증하며 백오피스 관리 API는 별도의 서버 전용 인증키로 보호합니다.
- 프로세스 목록, 이벤트 로그, 파일명 등 민감할 수 있는 정보는 백오피스 데이터베이스에 저장하지 않습니다.
- 원격 연결의 기본 주소를 검증된 HTTPS 운영 API로 변경하고 외부 HTTP API 폴백을 제거했습니다.
- 앱 설치별 장비 식별자를 안전하게 생성하고 재실행 후에도 동일한 PC로 인식합니다.

## 설치 파일

- `PC-Management-Assistant-1.0.16-setup.exe`: Windows 설치 프로그램
- `PC-Management-Assistant-1.0.16-windows-portable.zip`: Windows 포터블 버전
- `PC-Management-Assistant-1.0.16-mac-x64.dmg`: Intel Mac 설치 이미지
- `PC-Management-Assistant-1.0.16-mac-arm64.dmg`: Apple Silicon Mac 설치 이미지
- macOS ZIP 파일은 자동 업데이트용 패키지입니다.

> macOS 패키지는 Apple Developer ID 서명 및 공증이 적용되지 않았습니다. 처음 실행할 때 Finder에서 앱을 Control-클릭한 후 **열기**를 선택해야 할 수 있습니다.

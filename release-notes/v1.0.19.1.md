# V1.0.19.1

## 채팅 연결 오류 수정

- AI 응답 대기시간을 75초로 늘려 서버가 응답을 생성하는 동안 앱이 먼저 연결을 끊는 문제를 수정했습니다.
- 실패한 채팅 요청을 다른 서버 주소로 자동 재전송하지 않도록 변경해 중복 처리와 사용량 차감을 방지했습니다.
- 응답 시간 초과와 서버 연결 실패를 구분해 한국어로 안내합니다.

## 설치 파일

- Windows: 설치 프로그램 및 포터블 ZIP
- macOS: Intel 및 Apple Silicon DMG, 자동 업데이트용 ZIP

표시 버전은 1.0.19.1이며, 자동 업데이트 비교를 위한 내부 버전은 1.0.20-revision.1입니다.

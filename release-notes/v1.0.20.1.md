# V1.0.20.1

## 시스템 모니터링 부하 감소

- 창을 닫거나 최소화하면 시스템 지표 수집 주기를 1분으로 늘리고, 전체 프로세스 조회를 멈춥니다. 창을 다시 열면 바로 지표 갱신을 시작합니다.
- Windows에서 RAM, 디스크, GPU, 네트워크 트래픽 등 반복 조회에 쓰이던 PowerShell 호출을 줄였습니다. GPU 모델과 전체 VRAM은 캐시하고, NVIDIA 사용률·VRAM 사용량·온도는 별도로 갱신합니다.
- 별도 네트워크 연결 감시와 이벤트 로그 자동 복구는 백그라운드에서도 작동합니다.

## 설치 파일

- Windows: 설치 프로그램 및 포터블 ZIP
- macOS: Intel 및 Apple Silicon DMG, 자동 업데이트용 ZIP

표시 버전은 1.0.20.1이며, 자동 업데이트 비교를 위한 내부 버전은 1.0.21-revision.1입니다.

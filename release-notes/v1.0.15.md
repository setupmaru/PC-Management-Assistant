## v1.0.14.1 대비 변경사항

### EVENTS 안전 자동 복구

- 최근 24시간의 Windows 오류·경고 이벤트를 수집할 때 지원되는 문제를 자동으로 감지하고 복구합니다.
- DNS 클라이언트 이벤트(ID 1014)는 DNS 캐시를 초기화합니다.
- Windows 시간 서비스 이벤트(ID 129, 134, 142)는 시간 서비스를 확인하고 동기화를 다시 요청합니다.
- Windows Update 이벤트(ID 20, 25, 31, 34, 35)는 업데이트 검색을 다시 요청합니다.
- 이벤트 메시지나 외부 명령을 그대로 실행하지 않고, 앱에 미리 등록한 정적 복구 명령만 실행합니다.

### 제어 및 안정성

- 자동 복구는 기본으로 켜지며 EVENTS 영역에서 끄거나 다시 켤 수 있습니다.
- 지원 이벤트가 있을 때 `지금 실행`으로 수동 재시도할 수 있고, 성공·실패 결과를 화면에 표시합니다.
- 같은 이벤트의 성공 기록을 보존해 중복 실행을 막고, 실패 작업은 6시간 간격·최대 3회로 제한합니다.
- 자동 복구를 지원하지 않는 이벤트는 기존처럼 상태만 표시하며 임의 변경을 수행하지 않습니다.

## 설치 파일

- `PC-Management-Assistant-1.0.15-setup.exe`: Windows 설치 프로그램
- `PC-Management-Assistant-1.0.15-windows-portable.zip`: Windows 포터블 버전
- `PC-Management-Assistant-1.0.15-mac-x64.dmg`: Intel Mac 설치 이미지
- `PC-Management-Assistant-1.0.15-mac-arm64.dmg`: Apple Silicon Mac 설치 이미지
- macOS ZIP 파일은 자동 업데이트용 패키지입니다.

> EVENTS 자동 복구는 Windows 전용입니다. macOS 패키지는 Apple Developer ID 서명 및 공증이 적용되지 않았습니다.

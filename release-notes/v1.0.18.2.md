# V1.0.18.2

- 회원가입·비밀번호 재설정 인증번호 메일이 발송되지 않던 문제를 수정했습니다. 서버가 Gmail 대신 자체 메일 서버(SMTP)로 인증 메일을 보냅니다.
- 관리자가 백오피스에서 관리 PC를 삭제할 수 있는 API를 추가했습니다.

## 안내

이번 변경은 API 서버 쪽 수정이며 데스크톱 앱 기능은 이전 버전과 같습니다. 인증 메일이 받은편지함에 보이지 않으면 스팸함을 확인해 주세요.

공개 버전은 `1.0.18.2`이며 자동 업데이트 비교에 사용하는 내부 SemVer는 `1.0.19-revision.2`입니다.

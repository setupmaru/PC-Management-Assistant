## v1.0.13 대비 변경사항

### GPU 대시보드

- 대시보드에 GPU 카드를 추가하고 `CPU → GPU → 메모리 → 디스크 → 네트워크` 순서로 재배치했습니다.
- 주 GPU의 모델명, 사용률, VRAM 사용량과 온도를 표시합니다.
- NVIDIA 측정값과 Windows GPU 성능 카운터를 함께 사용해 AMD 환경의 사용률 수집도 보완했습니다.
- 측정값을 제공하지 않는 GPU는 잘못된 `0%` 대신 `--`로 표시합니다.
- 마지막 네트워크 카드를 전체 폭으로 표시해 빈 공간을 정리했습니다.

### macOS 지원

- Intel Mac(x64)과 Apple Silicon Mac(arm64)용 DMG 및 ZIP 패키지를 추가했습니다.
- macOS에서는 네이티브 창 제어 버튼을 사용합니다.
- PowerShell이 필요한 Windows 이벤트, 부팅 최적화, 상세 네트워크 감시, Windows Update 및 시스템 유지보수 수집기는 macOS에서 실행하지 않습니다.
- macOS에서도 CPU, GPU, 메모리, 디스크, 네트워크, 상위 프로세스와 AI 채팅 기능을 사용할 수 있습니다.

### 빌드 및 배포

- Windows와 macOS 패키지를 병렬 생성한 뒤 하나의 GitHub 릴리스에 게시하도록 배포 작업을 통합했습니다.
- GitHub Actions를 Node.js 24 기반 최신 호환 버전으로 갱신했습니다.

## 설치 파일

- `PC-Management-Assistant-1.0.14-setup.exe`: Windows 설치 프로그램
- `PC-Management-Assistant-1.0.14-windows-portable.zip`: Windows 포터블 버전
- `PC-Management-Assistant-1.0.14-mac-x64.dmg`: Intel Mac 설치 이미지
- `PC-Management-Assistant-1.0.14-mac-arm64.dmg`: Apple Silicon Mac 설치 이미지
- macOS ZIP 파일은 자동 업데이트용 패키지입니다.

> macOS 패키지는 Apple Developer ID 서명 및 공증이 적용되지 않은 초기 배포본입니다. 처음 실행할 때 Finder에서 앱을 Control-클릭한 후 **열기**를 선택해야 할 수 있습니다.

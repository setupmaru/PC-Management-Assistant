# V1.0.19

- 부팅 정보 수집이 끝났는데도 실측 항목이 없으면 계속 “분석 중”으로 표시하던 문제를 수정했습니다.
- 부팅 성능 기록 없음, 로그 비활성화, 접근 권한 부족, 조회 실패를 구분하고 필요한 조치를 안내합니다.
- 부팅 최적화 카드에 새로 고침을 추가했습니다. 최초 수집 실패 후에도 다시 조회할 수 있습니다.
- 실측 지연이 없는 경우 상세 화면에서 전체 시작 항목을 바로 확인하고 관리할 수 있습니다.
- 중복 조회는 진행 중인 수집 결과를 함께 기다리며, 누락된 부팅 시간을 0초로 표시하지 않습니다.

부팅 시간은 Windows에 남아 있는 성능 이벤트 기록을 사용합니다. 로그가 꺼져 있거나 기록이 없다면 안내에 따라 로그를 켜고 Windows를 다시 시작한 뒤 새로 고침해주세요.

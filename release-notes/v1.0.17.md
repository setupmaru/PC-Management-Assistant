# V1.0.17

- 설정에서 계정별 AI 채팅 모델을 선택하고 저장할 수 있습니다.
- 경제형 GPT-4o mini, 기본 균형형 GPT-5.4 mini, 고급형 GPT-5.5를 제공합니다.
- GPT-6 Astra는 지정된 전용 계정에서만 선택할 수 있습니다. 전용 계정도 기본값은 균형형입니다.
- 저장한 설정은 다른 로그인 세션에서도 유지되며 다음 채팅부터 적용됩니다.
- Free 채팅 제한, Plus 일일 한도, Pro 이용 정책은 유지됩니다.

## 데스크톱 재배포 수정

- React와 DOM 렌더러 버전 불일치로 시작 화면이 비어 보이는 문제를 수정했습니다. React, React DOM, 테스트 렌더러를 동일한 19.2.4 버전으로 고정했습니다.
- 동일한 V1.0.17 재배포이므로 기존 V1.0.17 설치에서는 자동 업데이트로 감지되지 않을 수 있습니다. 수정된 설치 파일을 직접 다운로드하여 다시 설치해야 합니다.

## Server rollout prerequisite

Apply the additive `server/schema.sql` migration before deploying the API and publishing the desktop release. `OPENAI_MODEL` no longer controls account chat. Verify provider access to each offered model separately before publication; local tests do not call paid upstream APIs.

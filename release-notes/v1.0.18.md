# V1.0.18

- 같은 내부망에서 API 서버 주소가 변경되어 로그인과 서버 연결에 실패하던 문제를 수정했습니다.
- 설치본에 포함되는 연결 설정과 앱의 기본 내부망 주소를 현재 서버 주소인 `192.168.0.119:3400`으로 맞췄습니다.
- 기존 V1.0.17 사용자는 이 버전으로 업데이트하면 수정된 기본 내부망 주소가 적용됩니다.

## 연결 안내

- 내부망 연결은 API 서버와 같은 네트워크에서 사용할 수 있습니다.
- 서버 주소가 다시 바뀌지 않도록 공유기에서 서버의 IP 주소를 예약하는 것을 권장합니다.
- 사용자 설정 폴더의 `pc-assistant.config.json`에 별도 서버 주소를 지정했다면 해당 설정도 확인해 주세요.
